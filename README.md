# Investment Tracker App (with Firebase)
This app allows multiple users to log in, add investment/profit entries, and calculate ROI with Firebase sync.

## Setup
1. Create a Firebase project at https://console.firebase.google.com
2. Enable **Email/Password Authentication** in Firebase Auth
3. Create a **Cloud Firestore** database
4. Replace the Firebase config in `script.js` with your project's credentials

## Run Locally
Just open `index.html` in your browser.

## Features
- Login/Signup
- Add investments or profits with reason/date
- Firebase real-time sync
- View all entries
